189 /*
190 ARCHITECTURE NOTE: Function Pointer Dispatch
191
192 All I/O handles are registered with the IOCP using key_io (0).
193 Dispatch happens via the function pointer stored in each scheduler_op.
194
195 When GQCS returns with an OVERLAPPED*, we cast it to scheduler_op*
196 and call the function pointer directly - no virtual dispatch.
197
198 The completion_key enum values are used only for internal signals:
199 - key_io (0): Normal I/O completion, dispatch via func_
200 - key_wake_dispatch (1): Timer wakeup, check dispatch_required_
201 - key_shutdown (2): Stop signal
202 - key_result_stored (3): Results pre-stored in OVERLAPPED
203 - key_posted: Carries a scheduler_op* in the OVERLAPPED pointer
204 - key_continuation: Carries a capy::continuation* in the OVERLAPPED pointer
